# 自研分级体系,而非直接采用 Lexile / 照搬牛津树

我们用自研的 15 级 **Level** 体系(底层锚定 CEFR + 课标词表),对外只做映射展示牛津树级别与校内年级,而不直接采用 Lexile 指数或照搬 RAZ/牛津树的级别名。理由:Lexile 是需付费授权的商标体系,且对低龄段颗粒度不足;照搬他人级别名有商标与法律风险,且定义权不在我们手里——而掌握分级定义,是「生成内容时精确约束 AI(Band 词表、句长)」以及产品护城河的前提。

## Considered Options

- **Lexile / AR 指数**:通用、有现成测难度工具,但商标授权付费、对中国家长是天书、低龄颗粒度不足。
- **照搬牛津树 / RAZ 级别**:家长认知度高,但有商标/法律风险,且无法控制级别定义。
- **按校内年级分级**:家长最懂,但同年级孩子英语水平差距极大,与「母语化习得」相悖。
