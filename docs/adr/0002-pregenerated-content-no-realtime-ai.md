# 内容一律预生成 + 人工审核,绝不实时调用大模型

所有 **Story** 都预生成、经程序校验 + AI 交叉审核 + 人工通读(/admin)后入库,绝不在用户请求时实时调用大模型生成面向孩子的内容。「兴趣定制」通过 **Interest Track** + **Name Slot**(确定性替换)实现,而非实时生成。

理由:境内实时生成式 AI 服务需要单独的算法/大模型备案,对个体户几乎不可行;且面向未成年人的实时生成内容无法事前保证内容安全。预生成让每一篇都能人工把关,把合规与内容风险降到趋零。

## Consequences

- 「定制感」受限于预设的主题轨道与名字槽位,无法做到「每个孩子每天一篇全新生成」——这是为合规与可控付出的、可接受的代价。
- 需要持续的内容生产投入(见 [0004](0004-validation-gate-and-theme-words.md) 的三层管线)。
