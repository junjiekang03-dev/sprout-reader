# 朗读用情感 TTS,不用声音克隆

故事朗读用高质量的**情感 TTS**(Azure Neural,`mstts:express-as` 温暖叙事 + 按级别调语速),而**不**克隆创始人或家长的声音来读英文正文。

理由:产品定位是「英语母语化学习」,朗读的**发音地道性**是核心卖点。声音克隆能完美复制音色,但复制不掉源音频里的发音——用一个非英语母语者的声音克隆来读分级读物,会把口音批量传给所有孩子,直接损害「地道输入」这一与原版读物竞争的命根子。而「有感情的朗读」这个真实目标,地道的情感 TTS 本就能满足,不需要克隆。

此外,共享音频架构下「创始人的声音读给陌生孩子」价值不明确;声音克隆属深度合成,面向未成年人会增加合规标识与声纹数据负担。

## Consequences

- 朗读音色/风格/语速通过 `AZURE_TTS_VOICE` / `AZURE_TTS_STYLE` / `AZURE_TTS_STYLEDEGREE` 环境变量可调,做 A/B。
- 「家长克隆自己声音读给**自己孩子**」的亲子价值不在此否定——它属于二期「亲子模式」(见 BACKLOG),且需解决英文发音(英文正文仍用地道 TTS、家长声音只用于中文陪伴)、声纹合规、GPU 成本。
