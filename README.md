# 芽芽阅读 SproutReader 🌱

为中国 8-12 岁孩子打造的英语**母语化分级阅读**平台(MVP)。

核心理念:二语习得靠**可理解输入**——每天读一篇、听一篇刚好适合自己水平的英文故事,
而不是背单词表和抠语法。差异化卖点:**孩子选兴趣主题,主角名字就是孩子自己**
(主题轨道 + 名字槽位,全部内容预生成并人工审核,无实时 AI 生成)。

## 已实现(MVP 闭环)

- **15 级自研分级体系**:底层锚定 CEFR + 课标词表(5 档累积词表),对外映射牛津树级别 + 校内年级双坐标 — [levels.ts](src/lib/levels.ts)
- **三层内容管线**:AI 生成 → 程序化校验(词表/句长/生词密度)→ 人工通读发布
  - `npx tsx scripts/story-prompt.ts <级别> <主题> [数量]` 生成单条创作 prompt(供人工粘贴)
  - 一条命令直连 API:`npm run content:generate`(需 `.env` 配 `ANTHROPIC_API_KEY`)→ 调 Claude 批量产出 → 校验 → 落 **draft** + 产出率统计;prompt 自动注入「同轨道已有情节,务必避开」做去重
  - 批量(多代理):Workflow 生成 + 对抗式安全审核 → `scripts/import-generated.ts` 过程序校验 → 落 **draft**(实测产出率约 80%)
  - `npm run validate:stories` 校验 content/stories/\*.json(上架门禁)
  - `/admin?key=<ADMIN_KEY>` 人工通读后「发布」或「退回」(第 3 层)
  - 主题词按兴趣轨道豁免「超纲/生词密度」(选恐龙轨道的孩子本就熟悉 dinosaur)
  - `npx tsx scripts/tts-generate.ts` 预生成 TTS 朗读(需 Azure key,无 key 时阅读器回退浏览器 Web Speech)
- **入级测评**:8 题自适应阶梯(L1-L12 题库),保守定级
- **每日阅读闭环**:按级别+兴趣推荐 → 点词查词(带发音)→ 听全文朗读 → 3 道理解题(选项乱序)→ 打卡
- **升降级建议**:连续高/低正确率时,主页提示升/降一级,家长可接受或忽略(纯逻辑有单测)
- **激励与家长侧**:连续打卡 streak、四周日历、家长周报页(免登录可分享,自带获客 CTA)
- **合规设计**:家长注册制(孩子仅英文昵称档案)、20 分钟护眼提醒、按会员订阅而非课时收费的产品形态
- **种子内容**:13 篇手写种子(L2-L11)+ 批量生成的 draft,全部通过分级校验
- **工程质量**:Vitest 单测(分级逻辑 + 校验器回归)、Husky pre-commit(prettier + typecheck + test)、危险 git 命令护栏

## 本地运行

```bash
npm install
npx prisma db push   # 创建 SQLite 开发库
npm run db:seed      # 导入故事 + 演示账号
npm run dev          # http://localhost:3000
```

演示账号:`13800138000` / `demo1234`(孩子 Leo,L3,恐龙+太空)

## 技术栈

Next.js 15 (App Router) + Tailwind v4 + Prisma。
开发用 SQLite,部署时把 [schema.prisma](prisma/schema.prisma) 的 provider 换成 `postgresql` 即可
(JSON 字段已按 String 存储,两库完全可移植)。

## 上线前行动清单(按依赖顺序)

### 只能你本人办的(第一周就启动,流程是串行依赖)

1. **注册个体工商户**(约 2 周)——经营范围写「软件开发/信息技术服务」,**避开「教育培训」字样**
2. **经营性 ICP 备案**(拿到执照后 2-4 周)——服务器须在境内(腾讯云/阿里云)
3. **微信支付商户号**(需执照)——收年费会员;按「会员订阅」收费,不做课时包
4. **微信服务号 + 认证**(需执照)——家长周报模板消息推送(当前版本周报靠链接分享,已可用)
5. **域名备案 + HTTPS**

### 工程侧(部署时)

- [ ] Postgres 实例 + `DATABASE_URL` 切换,`SESSION_SECRET` 换随机值
- [ ] 短信验证码注册(当前为手机号+密码,生产必须加验证码防撞库)
- [ ] Azure/MiniMax TTS key 配置,跑 `tts-generate.ts`,音频上 COS/OSS + CDN
- [ ] 故事题目选项乱序已做;入级测评题库扩充到每级 4+ 题
- [ ] 隐私政策 + 儿童个人信息保护规则页面(参照《儿童个人信息网络保护规定》)

### 内容侧(持续)

- [ ] 用 `story-prompt.ts` 批量生成,目标首发 300 篇(当前 13 篇验证管线)
  - 每篇必须人工通读后才能 seed(管线的第 3 层,不可省)
  - 词表需对照《义务教育英语课程标准》附录逐档扩充(当前为启动词表)
- [ ] 每周补 20-30 篇,优先覆盖 L3-L8(目标用户主力区间)

## 验证标准(双方共识,2026-06 定)

- 3 个月内上线 → 内测 8 周:30 个家庭中 ≥30% 坚持每周读 4 天 → 达标后开付费
- 再 6 个月:100 个年费会员(定价 200-400 元/年,Freemium:免费每天 1-2 篇)
- 止损线:留存不达标回炉最多两次;付费 6 个月不过 50 人重新评估
